# World News in One Image — 23 November 2026

Entry for the [make.fun](https://make.fun) bounty
`news-image-20261123` — $100, top 50 split.

## What it does

`main.py` (Python 3, standard library only) copies the pre-built
`entry.png` (768×1024, 421,752 bytes) to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
No network, deterministic output.
